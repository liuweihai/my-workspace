# 学习进度追踪器

## 功能

帮助用户管理结构化的学习记录，包括：
- 记录每日学习内容和心得
- 维护知识地图（已掌握 / 学习中 / 待学习）
- 生成复习提醒和学习建议

## 学习日志格式

每次用户学习新内容后，将记录保存到 `learning-log/` 目录：

```markdown
# 学习日志 - YYYY-MM-DD

## 今日学习
- **主题**: [技术/概念名称]
- **时长**: [大概时间]
- **难度**: ⭐~⭐⭐⭐⭐⭐

## 核心要点
1. [要点1]
2. [要点2]

## 代码实践
（如果有的话，附上关键代码片段）

## 疑问和待解决
- [ ] [问题1]

## 下一步计划
- [ ] [计划1]
```

## 知识地图格式

维护一个 `KNOWLEDGE_MAP.md` 文件：

```markdown
# 知识地图

## ✅ 已掌握
- [x] 技术A — 掌握日期，简要说明

## 📖 学习中
- [/] 技术B — 开始日期，当前进度

## 📋 待学习
- [ ] 技术C — 优先级，预计开始时间
```

## 步骤

1. 检查 `learning-log/` 目录是否存在，不存在则创建
2. 检查 `KNOWLEDGE_MAP.md` 是否存在，不存在则创建模板
3. 根据用户请求，执行以下操作之一：
   - **记录学习**：创建新的日志条目
   - **查看进度**：读取并汇总知识地图
   - **复习提醒**：查找超过 7 天未复习的主题
   - **规划学习**：根据知识地图生成下一步建议

## 验证
- 确认日志文件格式正确
- 确认知识地图已更新
