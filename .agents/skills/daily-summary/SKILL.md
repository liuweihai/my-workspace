# 日报/周报生成器

## 功能

自动汇总工作成果，生成结构化报告。

## 日报模板

```markdown
# 工作日报 — YYYY-MM-DD (周X)

## 📊 今日概况
- 提交次数: N
- 修改文件数: N
- 新增代码行: +N / 删除: -N

## ✅ 完成的工作
1. [任务描述] — [关联文件/模块]
2. ...

## 🔄 进行中的工作
1. [任务描述] — 进度 XX%
2. ...

## 🚧 遇到的问题
1. [问题描述] — [状态: 已解决/待解决]
2. ...

## 📋 明日计划
1. [计划1]
2. ...
```

## 步骤

### 生成日报
1. 运行 `git log --since="today 00:00" --oneline` 获取今日提交
2. 运行 `git diff --stat HEAD~N` 分析代码变更统计
3. 检查是否有 TODO 或 FIXME 标记的变更
4. 按模板生成日报，保存到 `reports/daily/YYYY-MM-DD.md`

### 生成周报
1. 运行 `git log --since="last monday" --oneline` 获取本周提交
2. 汇总每日日报（如果有）
3. 生成周报，保存到 `reports/weekly/YYYY-WNN.md`

## 验证
- 确认 git 日志正确获取
- 确认报告文件已保存到正确位置
