# 微信公众号自动化发文与排版方案

> **本文档定位与作用**：本文档旨在定义「微信公众号发文」项目的整体实现路径，涵盖 Markdown 自动化排版渲染、微信公众号官方 API 接口对接、素材封面合成、草稿箱管理及自动化群发流程，彻底解决内容发布的手工重复操作。

---

## 一、项目目标与核心能力

通过 AI 结合自动化脚本，实现微信公众号文章从**选题构思 ➔ 自动成文 ➔ 优雅排版 ➔ 自动推送草稿箱 ➔ 飞书通知确认**的全自动化闭环。

- **高颜值自动排版**：将标准 Markdown 转换为微信公众号支持的内联 CSS 富文本，包含特色大标题、引用边框、重点高亮卡片与代码美化；
- **官方 API / 草稿箱打通**：基于微信公众平台开发者 API（AppID / AppSecret），免人工网页复制粘贴，直接调用接口保存到官方草稿箱；
- **智能封面图与配图处理**：自动裁剪或通过 AI 生成符合 2.35:1 官方比例的精美封面图，并上传至微信永久素材库获取 media_id；
- **双保险确认机制**：草稿上传成功后，通过飞书机器人向手机推送预览卡片，点击即可在手机微信上审核草稿。

---

## 二、系统架构设计

```
[选题与 Markdown 原文] ➔ [排版渲染引擎 (Markdown to Inline CSS)] ➔ [封面与素材上传 (Media API)] ➔ [草稿箱同步 (Draft API)] ➔ [飞书审核通知]
```

### 1. 核心模块组成
- `renderer/theme_styler.py`：公众号样式渲染器，内嵌科技/学术/简约多种风格的 CSS 样式主题；
- `wechat/client.py`：微信公众号开放接口客户端（access_token 缓存刷新、图片素材上传、草稿创建）；
- `publisher.py`：发布调度器，串联“素材上传 ➔ 生成文章草稿 ➔ 飞书推送审核”。

---

## 三、环境依赖与准备工作

1. **微信公众平台开发者凭证**：
   - `WECHAT_APP_ID`：开发者 ID
   - `WECHAT_APP_SECRET`：开发者密码
   - `WECHAT_IP_WHITELIST`：公众号后台 IP 白名单（需将执行机器公网 IP 添加至白名单）；
2. **知识库联动**：每次生成并上传的微信文章原文，同时自动备份归档到飞书知识库 `📁 公众号发文` 目录下。
