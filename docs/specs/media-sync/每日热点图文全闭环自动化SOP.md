# 每日热点爆款图文自动化实操指南（开箱即用保姆级手册）

> **本文档是做什么的？**
> 这是一份任何人或任何 AI 工具（不论是 Antigravity、Claude、Cursor、Python 脚本等）都能直接照着一步步操作的实操手册。核心目的：**每天全自动抓取百度和头条的前 10 个热门新闻，写成接地气、有冲突感的爆款自媒体图文（以《买9斤蜜薯》为标杆），自动生成 3:2 写实大图与大字封面，打包成断网也能打开的单文件 HTML，并自动存入 Google 网盘。**

---

## 一、一分钟搞懂：这个系统怎么跑？

整个流程其实就像一个流水线工厂，只分 4 个简单环节：

```
[1. 抓热点] ➔ [2. 写爆款故事] ➔ [3. 生成场景大图] ➔ [4. 脚本一键组装] ➔ [自动存入网盘]
```

1. **抓热点**：每天早上看一眼百度或头条热搜，挑出 10 个真实发生的热门事件。
2. **写故事**：不要打官腔，按照我们固定的“蜜薯文爆款结构”写一篇 700~1000 字的故事。
3. **做配图**：用任何生图工具生成 1~3 张 3:2 的写实照片（最少 1 张做封面底图）。
4. **跑脚本**：把文字和图片路径丢给我们的排版脚本 `hotnews_builder.py`，它会自动做大字封面、做排版、做格式检查，最后生成 HTML 存进网盘。

## 二、爆款文章长什么样？（牢记 7 条死规矩）

我们之前摸索过很多版，最后发现：**只要文章写得像机关公文，就没人看；只有写得像《买9斤蜜薯》那样有冲突、有人情味，才是爆款。** 无论谁来写，必须严格遵循以下 7 条：

### 1. 标题字数卡死在 20 到 28 个字之间
- 包括所有逗号、感叹号、冒号在内，总字数必须 `>= 20` 且 `<= 28` 个字！
- **文件名和正文最顶上的第一行大标题，必须一字不差完全相同**。
- *合格范例*：`四部门全面叫停汽车速成乱象：严禁全隐藏把手与折叠屏！`（正好 26 字）

### 2. 封面必须是“大字封面”（自媒体标配）
- 头条和百家号的读者第一眼看的就是封面上的大字。
- 封面规格固定为 **3:2 比例**：
  - 底下是一张逼真的新闻现场或特写照片；
  - 蒙上一层半透明黑色遮罩（保证字看得清）；
  - 中间放 **48~52 号的超粗大字**（白字配合鲜黄大字）；
  - 底部带一条红线事件说明（如：`📍 核心事实：从百元跌至十几元 · 蟹农损失惨重`）。
  - *放心，我们的脚本会自动帮你把这些元素合成为一张图片，你只需要提供底图和文字。*

### 3. 正文配图：1 到 3 张，不强制死板
- 不是每篇都要硬凑 3 张图：
  - **普通热点**：只要 1 张大字头图就行；
  - **剧情复杂的大热点**：在正文第 2 节和第 3 节前，各插 1 张真实的场景照片（整篇共 2~3 张图）。
- 所有图片必须是 3:2 比例的写实照片，别用卡通或抽象插画。

### 4. 正文必须有“四大金刚”结构（缺一不可）
文章正文按以下 4 块组织，排版才好看：
- **① 冲突导读框（粉红底框）**：一上来就放矛盾最激烈的那句话，抓住眼球（例如：“我就不退，有本事你亲自过来拿！”）；
- **② 三个情节小标题（红线竖标）**：按“发生冲突 ➔ 调查内幕 ➔ 最终结果”把事情讲清楚，标题要有悬念；
- **③ 观点总结卡片（浅绿底框）**：结尾讲点公道话，讲法律底线或做人常识；
- **④ 读者互动栏（浅灰底框）**：抛出一个大家能参与讨论的问题，比如：“这事换作是你，你会怎么做？欢迎留言！”

### 5. 彻底去“AI味”，讲人话！
- **严禁出现的词汇**：`协同推进`、`多维透视`、`深层原因剖析`、`总的来说`、`综上所述`、`在当今快节奏社会`。
- **正文字数**：纯汉字字数控制在 **700 ~ 1000 字**，不要注水，把事情说透就行。

### 6. 代码里不要留任何注释
- HTML 文件里彻底删除 `<!-- -->` 和 `/* */` 注释，保持代码干干净净。
- 也不要加作者栏、阅读时长、阅读量等假数据。

### 7. 纯单文件自包含（零依赖）
- 所有图片必须转成 Base64 塞进这一个 HTML 文件里。
- 好处是：哪怕你把这个文件拷到断网的手机或电脑上，双击直接就能看，图片永远不会挂掉。

## 三、小白也能跑通的操作步骤（一步一步来）

### 第一步：准备好你的排版脚本
把项目里的 `scripts/hotnews_builder.py` 放在你的电脑里（比如 `/Users/<你的名字>/hotnews_automation/scripts/hotnews_builder.py`）。

> 💡 **这个脚本是干啥的？**  
> 它是你的“质检员”和“排版工人”。只要把写好的文字和图片传给它，它会自动检查标题是不是 20~28 字、会自动生成大字封面、会自动把图片转成 Base64、会自动保存到 Google 网盘。如果字数不对，它会直接报错提醒你修改，绝不让半成品溜出去。

## 四、历史踩坑血泪史（大白话避坑指南）

我们在测试过程中遇到了 5 个大坑，这里用最通俗的话记下来，后人千万不要再踩：

| 曾经遇到的问题 | 为什么会发生？（大白话） | 怎么根治？（记住这句话） |
| :--- | :--- | :--- |
| **1. 误用了小米 MiMo 模型** | 一开始偷懒，直接搬了以前在服务器上的老脚本，跑去调外部 API 了。 | **立刻删掉！** 既然要在本地闭环，就用本地 Agent 自带的大模型和生图，别搞第三方。 |
| **2. 文章写得像政府工作报告** | 没有给 AI 明确的标准，AI 自己自由发挥，全是“协同推进”、“多维透视”等空话套话。 | **以《买9斤蜜薯》为死规矩**，必须有导读框、情节小标题、观点卡，不准说空话。 |
| **3. 插图不见了，完成率只有30%** | AI 偷懒只生成了一张封面，忘了给正文故事情节配图。 | **写进脚本强制检查**：最少 1 张封面，长故事要 2~3 张图，并且自动合成大字封面。 |
| **4. Google 网盘里找不到文件** | 脚本里把云盘路径的邮箱名字写错了（qq.com 和 gmail.com 搞混了）。 | **看清本地挂载的真实文件夹路径**，不同电脑用户名可能不一样（Mac mini 是 `gang`，MacBook 是 `gg`）。 |
| **5. 连续生图被接口限流了** | 10 篇文章连续生成 30 张图，2分钟内密集请求，触发了 Google 生图的并发保护。 | **两个办法搞定**：① 动态配图（1~3张，总量减半）；② 每做完一篇文章主动休眠 60 秒再做下一篇。 |

## 五、怎么配置每天早晨 7 点自动运行？

### 场景 A：使用 Antigravity 运行（最推荐）
在 Mac mini 上的 Antigravity 界面操作：
1. 配置文件在：`~/.gemini/config/sidecars/daily-hot-news-publisher/sidecar.json`
2. 打开 Antigravity 左侧的 **`Automations`**；
3. 找到 **`每日热点新闻原生全闭环生成`**；
4. 把右侧的**滑块开关（Toggle）点亮开启**；
5. 每天早晨 07:00，它就会自动唤醒，自己抓新闻、自己写故事、自己生图、自己调用 `hotnews_builder.py` 存进 Google 网盘。

### 场景 B：使用其他 Agent 或定时任务（如 Claude / 脚本定时）
如果不使用 Antigravity 内置的 sidecar，可以用系统自带的 `crontab`：
```bash
0 7 * * * python3 /你的路径/run_daily_hotnews.py
```
让你的脚本自动调用你喜欢的生图工具和语言模型，拼出 `article.json`，最后调用 `hotnews_builder.py` 即可，逻辑一模一样！

## 六、换电脑 / 换 Agent 后的“5分钟自检清单”

如果你换了一台新电脑，或者来了一个全新的 AI 助手，问它这 5 个问题，全部打钩就代表可以立刻使用：

- [ ] **电脑环境**：有没有 Python 3？Google 网盘挂载好了没有？
- [ ] **脚本就位**：`hotnews_builder.py` 复制过去了吗？里面的保存路径改对了吗？
- [ ] **生图测试**：能不能正常生成 3:2 的写实图片？
- [ ] **跑个样稿**：拿上面的 `article.json` 跑一次命令，能不能在 Google 网盘看到大字封面和 HTML？
- [ ] **定时开启**：Automations 面板里的开关是绿色的吗？

**只要这 5 个清单确认无误，任何新环境都能直接开箱即用，再也不需要从头摸索！**
