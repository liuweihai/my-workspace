# 个人工作台核心需求规格说明书 (Spec)

- **版本**: V1.0 (规范驱动开发首期)
- **核心定位**: 个人每日工作与成长总控台
- **设计哲学**: 告别生拉硬套与信息过载，围绕「昨天进展 ➜ 今天计划 ➜ 当前进度」三大核心心智构建。

---

## 一、用户核心意图与痛点 (Why & Intent)

### 1. 当前痛点
* **记忆碎片化**：做过什么容易忘，不知道昨天交付了什么，每天打开电脑需要重新回忆上下文。
* **目标与行动脱节**：宏观项目（如公众号长文、自动化）进度不明朗，容易陷入无意义的琐事中。
* **界面花哨但无用**：市面上的仪表盘充斥着大量虚假的统计图表，缺乏真实可操作的行动流与即时交互。

### 2. 核心用户心智 (3 秒原则)
用户每天打开工作台，只需要在 3 秒钟内获得 3 个最真实的反馈：
1. **昨天做成了什么？**（昨天的进展、成果物、交付记录）
2. **今天必须做什么？**（今日核心计划、待办流水、快速打勾与撤销）
3. **当前全局走到哪了？**（各个项目的真实进度百分比、唯一步伐 Next Action）

## 二、功能规格与界面线框 (In-Scope & Layout)

### 1. 核心信息架构 (三栏/三块流式布局)

```
+-------------------------------------------------------------------------------+
|  ✦ 个人工作台                  [快速录入今日行动...   Enter]      🟢 SQLite 就绪 |
+-------------------------------------------------------------------------------+
|                                                                               |
|  【左栏：昨天的进展】        【中栏：今天的计划】         【右栏：当前全局进度】  |
|  Yesterday's Done           Today's Focus & Action       Project Roadmap      |
|                                                                               |
|  ✓ 固化交付 SOP 引擎         📌 [Top 1] 梳理首期选题打样   🔴 公众号深度长文       |
|    产出物: SKILL.md (20:10)  📌 [Top 2] 验证工作台核心流   [=====>      ] 15%     |
|                                                            ➜ 下一步: 梳理样章      |
|  ✓ 打通 Mac mini SSH MCP    --------------------------                        |
|    产出物: 原生工具 (18:40)    ☐ 测试勾选与 5s 撤销       🟡 每日热点自动化       |
|                                ☐ 记录 3 个长文选题候选    [============> ] 90%   |
|  ✓ 每日热点自动化打样完成                                  ➜ 搁置待命: 待发布理顺  |
|    产出物: 蜜薯退款长文HTML   + 新增一条行动...                                |
|                                                           🟢 Mac mini SSH 通道  |
|  昨日交付数: 3 项           今日剩余待办: 3 项           [==============] 100%  |
|                                                                               |
+-------------------------------------------------------------------------------+
|  底部浮动 Toast: ✓ 已完成「XXX」 · [ ↶ 撤销 (5s) ]                           |
+-------------------------------------------------------------------------------+
```

### 2. 模块细化规格

#### 模块 A：昨天的进展 (Yesterday)
* **内容来源**：自动归集昨天（或上一天完成时间戳）的所有已完成任务及关联成果物。
* **要素**：
  * 完成事项名称
  * 产出物标签（可点击跳转或标注文件路径）
  * 完成时间点（如 `18:40 完成`）
  * 统计摘要（如 `昨天共闭环 3 个关键交付`）

#### 模块 B：今天的计划 (Today)
* **核心焦点 (Top 1~3)**：用视觉微高亮标出今日决不能妥协的核心突破点。
* **即时待办流**：
  * 点击复选框：平滑划线动效，延迟淡出移入已完成。
  * 5 秒防误触撤销：底部弹出浮动 Toast，倒计时 5 秒内点击 `↶ 撤销` 立即在数据库中回滚。
* **快捷捕获**：页面顶部或列表末尾单行输入，按回车直接写入待办。

#### 模块 C：当前进度 (Roadmap & Progress)
* **项目卡片**：
  * 项目名称 + 状态标识（🔴 重点攻坚中 / 🟡 搁置待命中 / 🟢 已闭环资产）。
  * 真实进度条（%）。
  * **唯一步伐（Next Action）**：每个项目只展示当前最重要的下一步，支持一键点击 `[+ 提为今日计划]` 直接塞入今天的行动流。
  * **决策与搁置原因备忘**：简明扼要写明为什么现在搁置、什么时候重启，避免大脑重复记忆。

## 三、可量化验收标准 (Acceptance Criteria)

- [ ] **AC-1 (三心智直达)**：工作台首屏无多余干扰，左/中/右清晰对应「昨天的进展」、「今天的计划」、「当前进度」，3 秒内可掌握全局。
- [ ] **AC-2 (平滑打勾与 5s 撤销)**：点击今天计划的任务勾选框，有流畅划线与移出动效；底部立即出现 5 秒倒计时 Toast；点击撤销任务原样瞬间还原。
- [ ] **AC-3 (唯一步伐一键流转)**：点击右栏项目卡片上的 `+ 提为今日计划`，该项目的下一步动作立即以今日任务的形式出现在中栏的计划列表，并存入 SQLite。
- [ ] **AC-4 (昨日进展自动沉淀)**：已完成任务自动按照完成日期归档，昨天的成果物清晰可查，不丢失任何工作记录。
- [ ] **AC-5 (纯本地持久化)**：所有状态持久化保存在本地 `workbench.db`，重启后刷新页面数据完全保留，零配置、零外部依赖。
